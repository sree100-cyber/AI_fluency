# Day 4 Lab – Will It Fit? (Agentic AI: Foundations and Open-Source Practice)

Copy this folder into your `day1_lab` folder (or open it in VS Code), activate `.venv`, then:

    python run_lab.py                    # runs everything, saves results in outputs/
    python run_lab.py --available 16     # same, using your own RAM/VRAM (GB)
    python vram_estimate.py              # Part B only
    python check_reality.py              # Part C only (needs Ollama; start a model first for `ollama ps`)
